Post Office Rules, 2024 — 50 MCQs

50 questions with answers and brief explanations.

Q1. The Post Office Rules, 2024 operate under which parent legislation?

  1. Post Office Act, 2023
  2. Companies Act, 2013
  3. RTI Act, 2005
  4. Finance Act, 2024

Answer: A

Explanation: They are subordinate rules under the Post Office Act, 2023.

Q2. Which instrument provides the parent statutory framework for the new postal regime?

  1. Post Office Act, 2023
  2. Postal Manual VIII
  3. Office Procedure Manual
  4. Annual report

Answer: A

Explanation: The Act is the parent legislation.

Q3. When revising a rule that may have been amended, the safest approach is to:

  1. check the latest official text
  2. use the oldest printed copy
  3. ignore amendments
  4. guess the current wording

Answer: A

Explanation: The latest applicable official text should be verified.

Q4. A proviso generally introduces:

  1. a qualification or exception
  2. a page number
  3. a title
  4. a staff list

Answer: A

Explanation: A proviso qualifies the main provision.

Q5. A provision using “shall” ordinarily indicates:

  1. a mandatory requirement
  2. a suggestion
  3. a definition
  4. a heading

Answer: A

Explanation: “Shall” ordinarily conveys an obligation, subject to context.

Q6. A provision using “may” generally indicates: (Practice 6)

  1. discretion or permission
  2. an absolute prohibition
  3. a definition
  4. a punishment

Answer: A

Explanation: “May” commonly indicates discretion or permission.

Q7. An amendment log should contain: (Practice 7)

  1. notification/effective date and change
  2. only a page colour
  3. only a staff name
  4. only a website link

Answer: A

Explanation: Those details make amendments traceable.

Q8. For exam revision, a useful rule table is: (Practice 8)
