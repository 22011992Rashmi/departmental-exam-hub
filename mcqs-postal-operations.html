MCQ PRACTICE

Postal Operations — 50 MCQs

50 questions with answers and brief explanations.

Q1. The first stage in a postal workflow is normally:

  1. acceptance/booking
  2. final audit
  3. archiving
  4. complaint disposal

Answer: A

Explanation: A postal service begins with acceptance/booking.

Q2. Correct sorting primarily helps ensure:

  1. correct routing
  2. higher leave balance
  3. lower stationery use
  4. file indexing

Answer: A

Explanation: Sorting supports correct routing.

Q3. A booking receipt primarily provides:

  1. evidence of acceptance/booking
  2. proof of final delivery in every case
  3. a disciplinary order
  4. a financial sanction

Answer: A

Explanation: A receipt evidences booking/acceptance; it is not automatically proof of delivery.

Q4. Tracking information is useful for:

  1. following movement stages
  2. replacing all records
  3. waiving charges
  4. changing the addressee

Answer: A

Explanation: Tracking provides movement information.

Q5. Delivery evidence helps establish:

  1. whether and to whom delivery was effected
  2. employee pay
  3. office rent
  4. manufacturing cost

Answer: A

Explanation: Delivery evidence supports proof of delivery.

Q6. A dispatch stage should primarily ensure: (Practice 6)

  1. correct segregation, routing and documentation
  2. personal correspondence
  3. salary processing
  4. leave approval

Answer: A

Explanation: Dispatch depends on correct routing and records.

Q7. An undelivered article should be handled according to: (Practice 7)

  1. the applicable service procedure
  2. personal preference
  3. customer guesswork
  4. an unrelated manual

Answer: A

Explanation: Undelivered items have prescribed treatment.

Q8. An accountable article requires greater attention to: (Practice 8)

  1. recorded custody and delivery evidence
  2. office decoration
  3. staff attendance only
  4. stationery colour

Answer: A

Explanation: Accountability requires traceable custody and delivery evidence.

Q9. A complaint record is useful because it: (Practice 9)

  1. creates a traceable service issue
  2. replaces all postal records
  3. changes the address automatically
  4. waives every charge

Answer: A

Explanation: Records support investigation and accountability.

Q10. A workflow chart should show: (Practice 10)

  1. sequence and responsibility
  2. only service names
  3. only fees
  4. only employee names

Answer: A

Explanation: A good flowchart maps stages and responsibility.
