MCQ PRACTICE

Financial Rules — 50 MCQs

50 questions with answers and brief explanations.

Q1. Financial propriety requires expenditure to be:

  1. authorized and for a proper public purpose
  2. personal and undocumented
  3. based only on verbal permission
  4. unrelated to official work

Answer: A

Explanation: Public expenditure requires proper purpose and authority.

Q2. A sanction is important because it:

  1. authorizes expenditure within competent authority
  2. replaces a bill
  3. is a postal receipt
  4. is a leave application

Answer: A

Explanation: Sanction is an authorization by competent authority.

Q3. Procurement records primarily support:

  1. transparency and accountability
  2. personal use
  3. mail sorting
  4. delivery evidence

Answer: A

Explanation: Documentation supports transparent procurement.

Q4. An advance should be:

  1. accounted for and adjusted as prescribed
  2. treated as personal income
  3. ignored
  4. destroyed from records

Answer: A

Explanation: Advances require accounting and adjustment.

Q5. A bill should be supported by:

  1. required documentation and approvals
  2. only a nickname
  3. no record
  4. a postal stamp only

Answer: A

Explanation: Bills require prescribed supporting records.

Q6. Delegated financial powers should be exercised: (Practice 6)

  1. within the delegated authority and conditions
  2. without any limit
  3. by any employee
  4. only verbally

Answer: A

Explanation: Delegation has defined scope and conditions.

Q7. Economy in public expenditure means: (Practice 7)

  1. avoiding unnecessary expenditure while meeting the requirement
  2. buying the cheapest item regardless of suitability
  3. spending the full budget
  4. avoiding all expenditure

Answer: A

Explanation: Economy concerns proper and efficient use of public money.

Q8. A procurement file should preserve: (Practice 8)

  1. approvals, quotations/bids and relevant records as applicable
  2. only the final invoice
  3. no supporting documents
  4. personal messages

Answer: A

Explanation: Procurement accountability depends on records.
