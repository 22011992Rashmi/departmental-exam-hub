MCQ PRACTICE

Office Procedure — 50 MCQs

50 questions with answers and brief explanations.

Q1. A good office note should normally begin with:

  1. relevant facts/background
  2. a joke
  3. a personal grievance
  4. a final signature

Answer: A

Explanation: The note should establish the relevant facts.

Q2. A draft is prepared to:

  1. communicate a proposed official decision/message
  2. replace the file
  3. avoid approval
  4. create a postal stamp

Answer: A

Explanation: Drafting converts an approved/proposed decision into official communication.

Q3. A reference in official correspondence helps:

  1. identify an earlier communication/document
  2. increase postage
  3. replace an enclosure
  4. change authority

Answer: A

Explanation: References establish document context.

Q4. A file should be handled so that:

  1. the decision trail remains traceable
  2. papers are removed without record
  3. notes are destroyed
  4. only verbal instructions remain

Answer: A

Explanation: Traceability is essential to office records.

Q5. An enclosure should be:

  1. identified/listed with the communication where applicable
  2. ignored
  3. sent without reference always
  4. treated as a new file automatically

Answer: A

Explanation: Enclosures should be properly identified.

Q6. A proposal in a note should normally be: (Practice 6)

  1. clear and linked to the relevant issue
  2. hidden in unrelated text
  3. unsupported by facts
  4. purely personal

Answer: A

Explanation: A decision-maker needs a clear, supported proposal.

Q7. A subject line should be: (Practice 7)

  1. concise and descriptive
  2. blank in every case
  3. a full paragraph
  4. unrelated to the case

Answer: A

Explanation: The subject identifies the matter quickly.

Q8. A draft should reflect: (Practice 8)

  1. the approved substance and appropriate official language
  2. personal slang
  3. unverified claims
  4. unrelated history

Answer: A

Explanation: Official drafting should be accurate and appropriate.

Q9. Record management supports: (Practice 9)

  1. retrieval and accountability
  2. postal sorting only
  3. salary fixation only
  4. vehicle maintenance

Answer: A

Explanation: Records preserve institutional memory and accountability.

Q10. A file reference helps: (Practice 10)

  4. change a sanction

Answer: A

Explanation: References support retrieval and continuity.
